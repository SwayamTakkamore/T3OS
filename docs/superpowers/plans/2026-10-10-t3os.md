# T3OS v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build T3OS, a Linux terminal agent-harness control surface that runs its own model↔tool loop against Gemma on HuggingFace or a local GGUF, with a polished Ink TUI, persisted sessions, permissions, MCP tools, and a thin Tauri shell over the same core.

**Architecture:** `packages/core` is a UI-free engine (provider layer, agent loop, tools, permissions, sessions, MCP client, config) that the TUI runs in-process and that `packages/server` exposes over HTTP+WebSocket for the `packages/desktop` Tauri shell. One `AgentEvent` vocabulary is the only UI boundary. An append-only JSONL session log is the source of truth; resume/fork are replay.

**Tech Stack:** TypeScript (ESM, Node 20+), pnpm workspaces, Vitest, Ink/React 18, `@huggingface/transformers`, Tauri v2, `@modelcontextprotocol/sdk`, `zod` for tool JSON schemas.

## Global Constraints

- TypeScript end-to-end; ESM (`"type": "module"`); Node.js `>=20`; target `ES2022`.
- pnpm workspaces; package names `@t3os/core`, `@t3os/cli`, `@t3os/tui`, `@t3os/server`, `@t3os/desktop`.
- **`packages/core` must have ZERO UI dependencies** — no `ink`, no `react`, no `@tauri-apps/*`. Enforced by a test.
- HuggingFace is the model source. **Do NOT add Ollama** or any closed provider.
- One `AgentEvent` union is the single UI boundary shared by TUI, server, and desktop. Never invent a second event vocabulary.
- Session JSONL is the source of truth; no database. In-memory state is derived by replay.
- Secrets: only `HF_TOKEN` in v1. Raw secret value is fetched only at HTTP-call time; never written to session log, config dumps, or error messages.
- Hard deny-list (`.t3os/`, `.git/`, `~/.ssh`) is enforced **before** policy and always wins, even in `auto-accept`.
- MCP tools default to class `execute` unless the server declares otherwise.
- Project config `<repo>/.t3os/config.json` is commit-safe: **no secrets** ever.
- Gemma is first-class; any HF model id must still work.
- License MIT.
- Local environment note: `rg` (ripgrep) is NOT installed on the dev machine — use editor/`grep`-based search, not `rg`, in commands.

```ts
import type { AgentEvent } from "./types.js";

export type ErrorScope = "provider" | "tool" | "boot" | "config";

export class T3osError extends Error {
  readonly scope: ErrorScope;
  constructor(scope: ErrorScope, message: string) {
    super(message);
    this.name = "T3osError";
    this.scope = scope;
  }
}

export function toErrorEvent(err: unknown, scope: ErrorScope): AgentEvent {
  const message = err instanceof Error ? err.message : String(err);
  const resolved = err instanceof T3osError ? err.scope : scope;
  return { type: "error", scope: resolved, message };
}
```

`packages/core/src/sessions/store.ts`:
```ts
import { createHash } from "node:crypto";
import { mkdir, readFile, readdir, writeFile, appendFile } from "node:fs/promises";
import { join } from "node:path";
import type { AgentEvent } from "../types.js";
import { sessionsDir } from "./paths.js";

export interface SessionMeta {
  id: string;
  title: string;
  createdAt: string;
  updatedAt: string;
  eventCount: number;
}

interface Header extends SessionMeta {
  kind: "t3os-session";
  version: 1;
}

export class SessionStore {
  readonly #dir: string;

  constructor(dir: string = sessionsDir()) {
    this.#dir = dir;
  }

  #path(id: string): string {
    return join(this.#dir, `${id}.jsonl`);
  }

  #newId(title: string): string {
    const stamp = new Date().toISOString().replace(/[:.]/g, "-");
    const slug = title.toLowerCase().replace(/[^a-z0-9]+/g, "-").replace(/^-|-$/g, "");
    const hash = createHash("sha1").update(`${stamp}:${title}`).digest("hex").slice(0, 6);
    return slug ? `${stamp}-${slug}-${hash}` : `${stamp}-${hash}`;
  }

  async #readAll(id: string): Promise<{ header: Header; events: AgentEvent[] }> {
    const raw = await readFile(this.#path(id), "utf8");
    const lines = raw.split("\n").filter((l) => l.trim().length > 0);
    const header = JSON.parse(lines[0]!) as Header;
    const events = lines.slice(1).map((l) => JSON.parse(l) as AgentEvent);
    return { header, events };
  }

  async #writeHeader(header: Header): Promise<void> {
    await mkdir(this.#dir, { recursive: true });
    await writeFile(this.#path(header.id), `${JSON.stringify(header)}\n`, "utf8");
  }

  async create(title = "untitled"): Promise<SessionMeta> {
    const now = new Date().toISOString();
    const header: Header = {
      kind: "t3os-session",
      version: 1,
      id: this.#newId(title),
      title,
      createdAt: now,
      updatedAt: now,
      eventCount: 0
    };
    await this.#writeHeader(header);
    return header;
  }

  async list(): Promise<SessionMeta[]> {
    await mkdir(this.#dir, { recursive: true });
    const files = (await readdir(this.#dir)).filter((f) => f.endsWith(".jsonl"));
    const metas = await Promise.all(
      files.map(async (f) => (await this.#readAll(f.replace(/\.jsonl$/, ""))).header)
    );
    return metas.sort((a, b) => b.updatedAt.localeCompare(a.updatedAt));
  }

  async append(id: string, event: AgentEvent): Promise<void> {
    const { header } = await this.#readAll(id);
    await appendFile(this.#path(id), `${JSON.stringify(event)}\n`, "utf8");
    header.updatedAt = new Date().toISOString();
    header.eventCount += 1;
    await writeFile(this.#path(id), `${JSON.stringify(header)}\n`, "utf8");
    const body = await this.#readAll(id);
    await writeFile(
      this.#path(id),
      `${JSON.stringify(header)}\n${body.events.map((e) => JSON.stringify(e)).join("\n")}` +
        (body.events.length ? "\n" : ""),
      "utf8"
    );
  }

  async replay(id: string): Promise<AgentEvent[]> {
    return (await this.#readAll(id)).events;
  }

  async resume(id: string): Promise<AgentEvent[]> {
    return this.replay(id);
  }

  async fork(id: string, atOffset: number, title = "fork"): Promise<SessionMeta> {
    const { events } = await this.#readAll(id);
    const branch = await this.create(title);
    for (const event of events.slice(0, atOffset)) {
      await this.append(branch.id, event);
    }
    return branch;
  }
}
```

```ts
import { readFile } from "node:fs/promises";
import { join } from "node:path";
import type { PermissionMode } from "../types.js";
import { sessionsDir } from "../sessions/paths.js";
import { DEFAULTS, type ConfigFile, type ResolvedConfig } from "./types.js";

export interface LoaderOptions {
  cwd: string;
  homeDir: string;
  env: NodeJS.ProcessEnv;
  flags?: Partial<ConfigFile>;
}

async function readJson(path: string): Promise<ConfigFile> {
  try {
    return JSON.parse(await readFile(path, "utf8")) as ConfigFile;
  } catch {
    return {};
  }
}

function fromEnv(env: NodeJS.ProcessEnv): ConfigFile {
  const out: ConfigFile = {};
  if (env.T3OS_MODEL) out.model = env.T3OS_MODEL;
  if (env.T3OS_PROVIDER === "hf" || env.T3OS_PROVIDER === "local") out.provider = env.T3OS_PROVIDER;
  if (env.T3OS_PERMISSION_MODE) out.permissionMode = env.T3OS_PERMISSION_MODE as PermissionMode;
  if (env.T3OS_MAX_TURNS) out.maxTurns = Number(env.T3OS_MAX_TURNS);
  if (env.T3OS_LOOP_THRESHOLD) out.loopThreshold = Number(env.T3OS_LOOP_THRESHOLD);
  if (env.T3OS_SESSION_DIR) out.sessionDir = env.T3OS_SESSION_DIR;
  return out;
}

const listMerge = (a?: string[], b?: string[]): string[] => [...(a ?? []), ...(b ?? [])];

export class ConfigLoader {
  readonly #opts: LoaderOptions;
  constructor(opts: LoaderOptions) {
    this.#opts = opts;
  }

  async resolve(): Promise<ResolvedConfig> {
    const { cwd, homeDir, env, flags } = this.#opts;
    const global = await readJson(join(homeDir, ".config", "t3os", "config.json"));
    const project = await readJson(join(cwd, ".t3os", "config.json"));
    const envCfg = fromEnv(env);

    const layers: ConfigFile[] = [global, project, envCfg, flags ?? {}];
    const pick = <K extends keyof ConfigFile>(key: K): ConfigFile[K] | undefined => {
      let value: ConfigFile[K] | undefined;
      for (const layer of layers) if (layer[key] !== undefined) value = layer[key];
      return value;
    };

    const mcpServers = Object.assign({}, global.mcpServers, project.mcpServers, flags?.mcpServers);

    return {
      model: pick("model") ?? DEFAULTS.model,
      provider: pick("provider") ?? DEFAULTS.provider,
      permissionMode: pick("permissionMode") ?? DEFAULTS.permissionMode,
      toolAllow: listMerge(pick("toolAllow"), undefined),
      toolDeny: listMerge(pick("toolDeny"), undefined),
      mcpServers,
      sessionDir: pick("sessionDir") ?? sessionsDir(),
      maxTurns: pick("maxTurns") ?? DEFAULTS.maxTurns,
      loopThreshold: pick("loopThreshold") ?? DEFAULTS.loopThreshold,
      theme: pick("theme") ?? DEFAULTS.theme,
      projectRoot: cwd
    };
  }
}
```

```ts
export interface SseEvent {
  event?: string;
  data: string;
}

export function parseSseChunks(chunks: string[]): SseEvent[] {
  const events: SseEvent[] = [];
  let buffer = "";
  for (const chunk of chunks) {
    buffer += chunk;
    let index: number;
    while ((index = buffer.indexOf("\n\n")) !== -1) {
      const block = buffer.slice(0, index);
      buffer = buffer.slice(index + 2);
      const dataLines: string[] = [];
      let eventName: string | undefined;
      for (const line of block.split("\n")) {
        if (line.startsWith("data:")) dataLines.push(line.slice(5).replace(/^ /, ""));
        else if (line.startsWith("event:")) eventName = line.slice(6).trim();
      }
      const data = dataLines.join("\n");
      if (data.length === 0 || data === "[DONE]") continue;
      events.push(eventName ? { event: eventName, data } : { data });
    }
  }
  return events;
}

export async function* sseLines(body: ReadableStream<Uint8Array>): AsyncGenerator<SseEvent> {
  const decoder = new TextDecoder();
  const reader = body.getReader();
  let buffer = "";
  try {
    for (;;) {
      const { done, value } = await reader.read();
      if (done) break;
      buffer += decoder.decode(value, { stream: true });
      const flushable: string[] = [];
      let index: number;
      while ((index = buffer.indexOf("\n\n")) !== -1) {
        flushable.push(buffer.slice(0, index + 2));
        buffer = buffer.slice(index + 2);
      }
      if (flushable.length > 0) {
        for (const event of parseSseChunks(flushable)) yield event;
      }
    }
    if (buffer.trim().length > 0) {
      for (const event of parseSseChunks([`${buffer}\n\n`])) yield event;
    }
  } finally {
    reader.releaseLock();
  }
}
```

```ts
import { T3osError } from "../errors.js";
import type { Delta, Message, ToolSchema } from "../types.js";
import { sseLines } from "./sse.js";
import type { Provider, ProviderCapabilities, StreamOptions } from "./types.js";

export interface HuggingFaceProviderOptions {
  model: string;
  token: string;
  baseUrl?: string;
  contextLength?: number;
  fetchImpl?: typeof fetch;
}

interface ChatChunk {
  choices?: Array<{
    delta?: {
      content?: string | null;
      tool_calls?: Array<{
        index: number;
        id?: string;
        function?: { name?: string; arguments?: string };
      }>;
    };
    finish_reason?: string | null;
  }>;
  usage?: { prompt_tokens?: number; completion_tokens?: number };
}

export class HuggingFaceProvider implements Provider {
  readonly id = "hf";
  readonly #opts: Required<Pick<HuggingFaceProviderOptions, "model" | "token">> & HuggingFaceProviderOptions;
  readonly #fetch: typeof fetch;

  constructor(options: HuggingFaceProviderOptions) {
    this.#opts = options;
    this.#fetch = options.fetchImpl ?? globalThis.fetch;
  }

  capabilities(): ProviderCapabilities {
    return {
      toolCalling: true,
      streaming: true,
      contextLength: this.#opts.contextLength ?? 8192
    };
  }

  async *streamChat(
    messages: Message[],
    tools: ToolSchema[],
    opts?: StreamOptions
  ): AsyncIterable<Delta> {
    const base = this.#opts.baseUrl ?? "https://api-inference.huggingface.co/v1";
    const body: Record<string, unknown> = {
      model: this.#opts.model,
      messages,
      stream: true
    };
    if (tools.length > 0) {
      body.tools = tools.map((t) => ({
        type: "function",
        function: { name: t.name, description: t.description, parameters: t.parameters }
      }));
    }
    if (opts?.maxTokens !== undefined) body.max_tokens = opts.maxTokens;
    if (opts?.temperature !== undefined) body.temperature = opts.temperature;

    const response = await this.#fetch(`${base}/chat/completions`, {
      method: "POST",
      headers: {
        "content-type": "application/json",
        authorization: `Bearer ${this.#opts.token}`
      },
      body: JSON.stringify(body),
      signal: opts?.signal
    });

    if (!response.ok) {
      throw new T3osError("provider", `HuggingFace request failed: ${response.status}`);
    }
    if (!response.body) {
      throw new T3osError("provider", "HuggingFace response had no body");
    }

    for await (const event of sseLines(response.body)) {
      let chunk: ChatChunk;
      try {
        chunk = JSON.parse(event.data) as ChatChunk;
      } catch {
        continue;
      }
      const choice = chunk.choices?.[0];
      const delta = choice?.delta;
      if (delta?.content) yield { type: "text", text: delta.content };
      for (const call of delta?.tool_calls ?? []) {
        if (call.id && call.function?.name) {
          yield { type: "tool_call_start", id: call.id, name: call.function.name };
        }
        const args = call.function?.arguments;
        if (args && call.id) {
          yield { type: "tool_call_delta", id: call.id, argsJsonDelta: args };
        }
      }
      if (choice?.finish_reason === "tool_calls") {
        for (const call of delta?.tool_calls ?? []) {
          if (call.id) yield { type: "tool_call_end", id: call.id };
        }
      }
      if (chunk.usage) {
        yield {
          type: "usage",
          inputTokens: chunk.usage.prompt_tokens ?? 0,
          outputTokens: chunk.usage.completion_tokens ?? 0
        };
      }
    }
    yield { type: "done" };
  }
}
```

```ts
import { resolvePreset, type ModelPreset } from "../presets/index.js";
import type { Delta, Message, ToolSchema } from "../types.js";
import type { Provider, ProviderCapabilities, StreamOptions } from "./types.js";

export type GenerateFn = (
  prompt: string,
  opts: { maxTokens: number; temperature: number; stopTokens: string[] }
) => AsyncIterable<string>;

export function renderPrompt(messages: Message[], preset: ModelPreset): string {
  if (preset.chatTemplate === "gemma") {
    const parts: string[] = [];
    for (const message of messages) {
      const role = message.role === "assistant" ? "model" : message.role;
      parts.push(`<start_of_turn>${role}\n${message.content}<end_of_turn>\n`);
    }
    parts.push("<start_of_turn>model\n");
    return parts.join("");
  }
  return messages.map((m) => `${m.role}: ${m.content}`).join("\n") + "\nassistant:";
}

async function transformersGenerate(modelId: string): Promise<GenerateFn> {
  const { pipeline } = await import("@huggingface/transformers");
  const generator = await pipeline("text-generation", modelId);
  return async function* generate(prompt, opts) {
    let queue: string[] = [];
    const streamer = {
      put(value: string) {
        queue.push(value);
      },
      end() {
        queue.push("\u0000");
      }
    };
    const outcome = generator(prompt, {
      max_new_tokens: opts.maxTokens,
      temperature: opts.temperature,
      do_sample: opts.temperature > 0,
      streamer
    });
    void outcome;
    for (;;) {
      if (queue.length === 0) {
        await new Promise((resolve) => setTimeout(resolve, 5));
        continue;
      }
      const next = queue.shift()!;
      if (next === "\u0000") return;
      yield next;
    }
  };
}

export interface LocalProviderOptions {
  modelId: string;
  generate?: GenerateFn;
  contextLength?: number;
}

export class LocalProvider implements Provider {
  readonly id = "local";
  readonly #modelId: string;
  readonly #preset: ModelPreset;
  readonly #contextLength: number;
  #generate?: GenerateFn;

  constructor(options: LocalProviderOptions) {
    this.#modelId = options.modelId;
    this.#preset = resolvePreset(options.modelId);
    this.#contextLength = options.contextLength ?? this.#preset.contextLength;
    this.#generate = options.generate;
  }

  capabilities(): ProviderCapabilities {
    return { toolCalling: false, streaming: true, contextLength: this.#contextLength };
  }

  async #load(): Promise<GenerateFn> {
    if (!this.#generate) this.#generate = await transformersGenerate(this.#modelId);
    return this.#generate;
  }

  async *streamChat(
    messages: Message[],
    _tools: ToolSchema[],
    opts?: StreamOptions
  ): AsyncIterable<Delta> {
    const generate = await this.#load();
    const prompt = renderPrompt(messages, this.#preset);
    const iterator = generate(prompt, {
      maxTokens: opts?.maxTokens ?? this.#preset.maxTokens,
      temperature: opts?.temperature ?? this.#preset.temperature,
      stopTokens: this.#preset.stopTokens
    });
    for await (const text of iterator) {
      if (opts?.signal?.aborted) throw new Error("aborted");
      if (text.length > 0) yield { type: "text", text };
    }
    yield { type: "done" };
  }
}
```

```ts
export function resolveInRoot(root: string, candidate: string): string {
  const absolute = resolve(root, candidate);
  const rel = relative(root, absolute);
  if (rel === "" || rel.startsWith("..") || isAbsolute(rel)) {
    throw new T3osError("permission", `path escapes workspace root: ${candidate}`);
```

```ts
export function globToRegExp(pattern: string): RegExp {
  let out = "^";
  for (let i = 0; i < pattern.length; i += 1) {
    const char = pattern[i]!;
    if (char === "*") {
      if (pattern[i + 1] === "*") {
        const followedBySlash = pattern[i + 2] === "/";
        out += followedBySlash ? "(?:.*/)?" : ".*";
        i += followedBySlash ? 2 : 1;
      } else {
        out += "[^/]*";
      }
    } else if (char === "?") {
      out += "[^/]";
    } else if ("\\^$.|+()[]{}".includes(char)) {
      out += `\\${char}`;
    } else {
      out += char;
    }
  }
  return new RegExp(`${out}$`);
}
```

```ts
import { assertNotAborted, resolveInRoot, type Tool, type ToolContext, type ToolResult } from "./types.js";

const MAX_GREP_MATCHES = 200;

async function walk(dir: string, root: string, out: string[]): Promise<void> {
  for (const entry of await readdir(dir, { withFileTypes: true })) {
    const full = join(dir, entry.name);
    if (entry.isDirectory()) {
      if (entry.name === "node_modules" || entry.name === ".git") continue;
      await walk(full, root, out);
    } else if (entry.isFile()) {
      out.push(relative(root, full).split(sep).join("/"));
    }
  }
}

function asString(args: unknown, key: string): string | undefined {
  const value = (args as Record<string, unknown> | undefined)?.[key];
  return typeof value === "string" ? value : undefined;
}

function asNumber(args: unknown, key: string): number | undefined {
  const value = (args as Record<string, unknown> | undefined)?.[key];
  return typeof value === "number" ? value : undefined;
}

export const readFileTool: Tool = {
  class: "read",
  schema: {
    name: "read_file",
    description: "Read a UTF-8 text file, returning lines prefixed with their 1-based line number.",
    parameters: {
      type: "object",
      properties: {
        path: { type: "string", description: "Path relative to the workspace root." },
        offset: { type: "number", description: "1-based first line to return." },
        limit: { type: "number", description: "Maximum number of lines to return." }
      },
      required: ["path"]
    }
  },
  async run(args: unknown, ctx: ToolContext): Promise<ToolResult> {
    assertNotAborted(ctx);
    const path = asString(args, "path");
    if (!path) return { ok: false, content: "read_file: missing path" };
    const absolute = resolveInRoot(ctx.root, path);
    const raw = await readFile(absolute, "utf8");
    const lines = raw.split("\n");
    const offset = Math.max(1, asNumber(args, "offset") ?? 1);
    const limit = Math.max(1, asNumber(args, "limit") ?? lines.length);
    const slice = lines.slice(offset - 1, offset - 1 + limit);
    const content = slice.map((line, index) => `${offset + index}: ${line}`).join("\n");
    return { ok: true, content, data: { totalLines: lines.length } };
  }
};

    description: "List the immediate children of a directory with their kind.",

export const globTool: Tool = {
  class: "read",
  schema: {
    name: "glob",
    description: "Find files by glob pattern (supports * and **), relative to the workspace root.",
    parameters: {
      type: "object",
      properties: { pattern: { type: "string" }, path: { type: "string" } },
      required: ["pattern"]
    }
  },
  async run(args: unknown, ctx: ToolContext): Promise<ToolResult> {
    assertNotAborted(ctx);
    const pattern = asString(args, "pattern");
    if (!pattern) return { ok: false, content: "glob: missing pattern" };
    const base = resolveInRoot(ctx.root, asString(args, "path") ?? ".");
    const files: string[] = [];
    await walk(base, ctx.root, files);
    const matcher = globToRegExp(pattern);
    const matches = files.filter((file) => matcher.test(file)).sort();
    return { ok: true, content: matches.join("\n"), data: matches };

export const grepTool: Tool = {
  class: "read",
  schema: {
    name: "grep",
    description: "Search file contents by regular expression, returning path:line: text.",
    parameters: {
      type: "object",
      properties: {
        pattern: { type: "string" },
        path: { type: "string" },
        include: { type: "string", description: "Glob of files to include, for example *.ts." }
      },
      required: ["pattern"]
    }
  },
  async run(args: unknown, ctx: ToolContext): Promise<ToolResult> {
    assertNotAborted(ctx);
    const pattern = asString(args, "pattern");
    if (!pattern) return { ok: false, content: "grep: missing pattern" };
    const expression = new RegExp(pattern);
    const base = resolveInRoot(ctx.root, asString(args, "path") ?? ".");
    const files: string[] = [];
    await walk(base, ctx.root, files);
    const include = asString(args, "include");
    const includeMatcher = include ? globToRegExp(include) : undefined;
    const matches: string[] = [];
    for (const file of files) {
      if (includeMatcher && !includeMatcher.test(file.split("/").pop() ?? file)) continue;
      if (matches.length >= MAX_GREP_MATCHES) break;
      const text = await readFile(join(ctx.root, file), "utf8").catch(() => "");
      const lines = text.split("\n");
      for (let index = 0; index < lines.length; index += 1) {
        if (expression.test(lines[index]!)) {
          matches.push(`${file}:${index + 1}: ${lines[index]}`);
          if (matches.length >= MAX_GREP_MATCHES) break;
        }
      }
    }
    return { ok: true, content: matches.join("\n"), data: matches };
  }
};
```

```ts
  const n = a.length;
  const m = b.length;
  const table: number[][] = Array.from({ length: n + 1 }, () => new Array<number>(m + 1).fill(0));
  for (let i = n - 1; i >= 0; i -= 1) {
    for (let j = m - 1; j >= 0; j -= 1) {
      table[i]![j] = a[i] === b[j] ? table[i + 1]![j + 1]! + 1 : Math.max(table[i + 1]![j]!, table[i]![j + 1]!);
    }
  }
  const ops: Op[] = [];
  let i = 0;
  let j = 0;
  while (i < n && j < m) {
    if (a[i] === b[j]) {
      ops.push({ kind: "keep", line: a[i]! });
      i += 1;
      j += 1;
    } else if (table[i + 1]![j]! >= table[i]![j + 1]!) {
      ops.push({ kind: "del", line: a[i]! });
      i += 1;
    } else {
      ops.push({ kind: "add", line: b[j]! });
      j += 1;
    }
  }
  while (i < n) ops.push({ kind: "del", line: a[i++]! });
  while (j < m) ops.push({ kind: "add", line: b[j++]! });
  return ops;
}

export function unifiedDiff(before: string, after: string, path: string): string {
  if (before === after) return "";
  const a = before.split("\n");
  const b = after.split("\n");
  const ops = diffLines(a, b);
  const body = ops
    .map((op) => (op.kind === "keep" ? ` ${op.line}` : op.kind === "del" ? `-${op.line}` : `+${op.line}`))
    .join("\n");
  return [`--- a/${path}`, `+++ b/${path}`, `@@ -1,${a.length} +1,${b.length} @@`, body].join("\n");
}
```

```ts
import { spawn } from "node:child_process";
import { relative, resolve } from "node:path";
import { T3osError } from "../errors.js";
import type { Tool, ToolContext, ToolResult } from "./types.js";
import { assertNotAborted } from "./types.js";

const DEFAULT_TIMEOUT_MS = 120_000;
const DEFAULT_MAX_BYTES = 64 * 1024;

function asString(args: Record<string, unknown>, key: string): string | undefined {
  const value = args[key];
  return typeof value === "string" ? value : undefined;
}

function asNumber(args: Record<string, unknown>, key: string): number | undefined {
  const value = args[key];
  return typeof value === "number" && Number.isFinite(value) ? value : undefined;
}

export interface ShellResult {
  exitCode: number;
  stdout: string;
  stderr: string;
  timedOut: boolean;
  truncated: boolean;
}

export interface RunShellOptions {
  cwd: string;
  command: string;
  timeoutMs?: number;
  maxBytes?: number;
  signal?: AbortSignal;
}

export function runShell(opts: RunShellOptions): Promise<ShellResult> {
  const timeoutMs = opts.timeoutMs ?? DEFAULT_TIMEOUT_MS;
  const maxBytes = opts.maxBytes ?? DEFAULT_MAX_BYTES;

  return new Promise<ShellResult>((resolvePromise) => {
    const child = spawn("bash", ["-lc", opts.command], {
      cwd: opts.cwd,
      env: process.env,
      stdio: ["ignore", "pipe", "pipe"],
    });

    let stdout = "";
    let stderr = "";
    let truncated = false;
    let timedOut = false;
    let settled = false;

    const append = (target: "out" | "err", chunk: Buffer): void => {
      const text = chunk.toString("utf8");
      if (target === "out") {
        stdout += text;
        if (stdout.length > maxBytes) {
          stdout = stdout.slice(0, maxBytes);
          truncated = true;
        }
      } else {
        stderr += text;
        if (stderr.length > maxBytes) {
          stderr = stderr.slice(0, maxBytes);
          truncated = true;
        }
      }
    };

    const finish = (exitCode: number): void => {
      if (settled) return;
      settled = true;
      clearTimeout(timer);
      opts.signal?.removeEventListener("abort", onAbort);
      resolvePromise({ exitCode, stdout, stderr, timedOut, truncated });
    };

    const timer = setTimeout(() => {
      timedOut = true;
      child.kill("SIGKILL");
    }, timeoutMs);

    const onAbort = (): void => {
      child.kill("SIGKILL");
    };
    opts.signal?.addEventListener("abort", onAbort, { once: true });

    child.stdout.on("data", (chunk: Buffer) => append("out", chunk));
    child.stderr.on("data", (chunk: Buffer) => append("err", chunk));
    child.on("error", () => finish(127));
    child.on("close", (code) => finish(code ?? 1));
  });
}

export const runShellTool: Tool = {
  schema: {
    name: "run_shell",
    description:
      "Run a shell command with bash -lc in the workspace root and return its combined output. " +
      "Use for builds, tests, git status, and other terminal operations.",
    parameters: {
      type: "object",
      properties: {
        command: { type: "string", description: "Shell command to execute." },
        cwd: {
          type: "string",
          description: "Relative working directory inside the workspace root. Defaults to the root.",
        },
        timeoutMs: {
          type: "number",
          description: "Wall-clock timeout in milliseconds. Defaults to 120000.",
        },
      },
      required: ["command"],
    },
  },
  class: "execute",
  async run(args: Record<string, unknown>, ctx: ToolContext): Promise<ToolResult> {
    assertNotAborted(ctx);
    const command = asString(args, "command");
    if (!command) {
      return { ok: false, content: "run_shell: missing required argument 'command'" };
    }

    const rel = asString(args, "cwd");
    let cwd = ctx.root;
    if (rel) {
      cwd = resolve(ctx.root, rel);
      const inside = relative(ctx.root, cwd);
      if (inside.startsWith("..") || inside === "") {
        throw new T3osError("permission", `cwd escapes workspace root: ${rel}`);
      }
    }

    const result = await runShell({
      cwd,
      command,
      timeoutMs: asNumber(args, "timeoutMs"),
      signal: ctx.signal,
    });

    const ok = result.exitCode === 0 && !result.timedOut;
    const parts: string[] = [];
    if (result.stdout.trim()) parts.push(result.stdout.trimEnd());
    if (result.stderr.trim()) parts.push(`[stderr]\n${result.stderr.trimEnd()}`);
    if (result.timedOut) parts.push(`[timed out]`);
    if (result.truncated) parts.push(`[output truncated]`);
    if (!ok) parts.push(`[exit code ${result.exitCode}]`);

    return {
      ok,
      content: parts.join("\n") || "(no output)",
      data: {
        exitCode: result.exitCode,
        timedOut: result.timedOut,
        truncated: result.truncated,
      },
    };
  },
};
```

```ts
import type { PermissionMode, ToolClass } from "../types.js";

export type PermissionDecision =
  | { outcome: "allow" }
  | { outcome: "deny"; reason: string }
  | { outcome: "ask"; reason: string };

export interface PermissionRequest {
  tool: string;
  toolClass: ToolClass;
  args: Record<string, unknown>;
}

export interface PermissionPolicy {
  mode: PermissionMode;
  evaluate(request: PermissionRequest): PermissionDecision;
  checkShell(command: string): PermissionDecision;
}

export const HARD_DENY_PATTERNS: RegExp[] = [
  /\brm\s+(-[a-zA-Z]*\s+)*-\/(\s|$)/,
  /\bmkfs(\.\w+)?\b/,
  /\bdd\b[^\n]*\bof=\/dev\//,
  /:\s*\(\s*\)\s*\{.*\}\s*;\s*:/,
  /\b(shutdown|reboot|poweroff|halt)\b/,
  /\bchmod\s+(-R\s+)?777\s+\//,
];

function matrix(mode: PermissionMode, toolClass: ToolClass): PermissionDecision {
  if (toolClass === "read") return { outcome: "allow" };
  if (mode === "auto-accept") return { outcome: "allow" };
  if (mode === "read-only") {
    return { outcome: "deny", reason: `${toolClass} tools are disabled in read-only mode` };
  }
  return { outcome: "ask", reason: `${toolClass} access requires approval` };
}

export function createPolicy(mode: PermissionMode): PermissionPolicy {
  return {
    mode,
    evaluate(request: PermissionRequest): PermissionDecision {
      if (request.toolClass === "execute") {
        const command = request.args["command"];
        if (typeof command === "string") return this.checkShell(command);
      }
      return matrix(mode, request.toolClass);
    },
    checkShell(command: string): PermissionDecision {
      for (const pattern of HARD_DENY_PATTERNS) {
        if (pattern.test(command)) {
          return { outcome: "deny", reason: `blocked by hard-deny rule: ${pattern}` };
        }
      }
      return matrix(mode, "execute");
    },
  };
}
```

> **Ordering rule:** `checkShell` runs `HARD_DENY_PATTERNS` **before** consulting the mode matrix, so a hard-denied command is refused even in `auto-accept` mode. Do not reorder these two blocks.

- `eventsToMessages(events: AgentEvent[]): Message[]` — pure projection from the session log back into provider messages.
- `hashArgs(args: unknown): string` — 8-hex-char digest of a key-sorted stringification, used for loop detection and permission decisions.
- `builtInTools(): Tool[]` — the seven built-in tools in a stable order.
- `runTurn(opts: RunTurnOptions): Promise<TurnResult>` — runs one turn to completion.
- `RunTurnOptions { provider: Provider; store: SessionStore; sessionId: string; policy: PermissionPolicy; root: string; tools?: Tool[]; prompt?: string; signal?: AbortSignal; onPermission?: (request: PermissionRequest, id: string) => Promise<ApprovalOutcome>; maxSteps?: number; maxRepeat?: number }`

- `TurnResult { reason: TurnEndReason; text: string; steps: number; inputTokens: number; outputTokens: number; events: AgentEvent[] }`

The loop never stores `Message[]`: history is always rebuilt from `store.replay(sessionId)` through `eventsToMessages`, so the JSONL log stays the single source of truth.

```ts
import type { AgentEvent, Message, ToolCall } from "../types.js";

export function eventsToMessages(events: AgentEvent[]): Message[] {
  const messages: Message[] = [];
  let openAssistant: Message | undefined;

  for (const event of events) {
    switch (event.type) {
      case "user_message":
        messages.push({ role: "user", content: event.text });
        openAssistant = undefined;
        break;
      case "text":
        if (openAssistant && openAssistant.content !== "" && !openAssistant.toolCalls) {
          messages[messages.length - 1] = {
            role: "assistant",
            content: openAssistant.content + event.text,
          };
          openAssistant = messages[messages.length - 1];
        } else {
          openAssistant = { role: "assistant", content: event.text };
          messages.push(openAssistant);
        }
        break;
      case "tool_call": {
        const call: ToolCall = { id: event.id, name: event.name, args: event.args };
        const last = messages[messages.length - 1];
        if (last && last.role === "assistant" && !last.content) {
          last.toolCalls = [...(last.toolCalls ?? []), call];
        } else {
          openAssistant = { role: "assistant", content: "", toolCalls: [call] };
          messages.push(openAssistant);
        }
        openAssistant = undefined;
        break;
      }
      case "tool_result":
        messages.push({
          role: "tool",
          toolCallId: event.id,
          name: event.name,
          content: event.output,
        });
        openAssistant = undefined;
        break;
      default:
        break;
    }
  }

  return messages;
}
```

```ts
import { createHash } from "node:crypto";
import { toErrorEvent } from "../errors.js";
import type { PermissionPolicy, PermissionRequest } from "../permissions/policy.js";
import type { Provider } from "../provider/types.js";
import type { SessionStore } from "../sessions/store.js";
import type { Tool, ToolContext } from "../tools/types.js";
import type { AgentEvent, Message, ToolCall, ToolClass, TurnEndReason } from "../types.js";
import { eventsToMessages } from "./project.js";

export type ApprovalOutcome = "allow" | "deny" | "session" | "always";

export interface RunTurnOptions {
  provider: Provider;
  store: SessionStore;
  sessionId: string;
  policy: PermissionPolicy;
  root: string;
  tools?: Tool[];
  prompt?: string;
  signal?: AbortSignal;
  onPermission?: (request: PermissionRequest, id: string) => Promise<ApprovalOutcome>;
  maxSteps?: number;
  maxRepeat?: number;
}

export interface TurnResult {
  reason: TurnEndReason;
  text: string;
  steps: number;
  inputTokens: number;
  outputTokens: number;
  events: AgentEvent[];
}

const DEFAULT_MAX_STEPS = 24;
const DEFAULT_MAX_REPEAT = 3;

export function hashArgs(args: unknown): string {
  return createHash("sha1").update(stableStringify(args)).digest("hex").slice(0, 8);
}

function stableStringify(value: unknown): string {
  if (value === null || typeof value !== "object") return JSON.stringify(value) ?? "null";
  if (Array.isArray(value)) return `[${value.map(stableStringify).join(",")}]`;
  const entries = Object.entries(value as Record<string, unknown>)
    .filter(([, entry]) => entry !== undefined)
    .sort(([a], [b]) => (a < b ? -1 : a > b ? 1 : 0));
  return `{${entries
    .map(([key, entry]) => `${JSON.stringify(key)}:${stableStringify(entry)}`)
    .join(",")}}`;
}

function parseArgs(json: string): unknown {
  if (json.trim() === "") return {};
  try {
    return JSON.parse(json);
  } catch {
    return {};
  }
}

function asRecord(value: unknown): Record<string, unknown> {
  return value !== null && typeof value === "object" && !Array.isArray(value)
    ? (value as Record<string, unknown>)
    : {};
}

export async function runTurn(opts: RunTurnOptions): Promise<TurnResult> {
  const {
    provider,
    store,
    sessionId,
    policy,
    root,
    tools = [],
    signal,
    onPermission,
    maxSteps = DEFAULT_MAX_STEPS,
    maxRepeat = DEFAULT_MAX_REPEAT,
  } = opts;

  const events: AgentEvent[] = [];
  const byName = new Map(tools.map((tool) => [tool.schema.name, tool]));
  const schemas = tools.map((tool) => tool.schema);
  const sessionAllowed = new Set<string>();
  const alwaysAllowed = new Set<string>();
  const repeats = new Map<string, number>();

  const emit = async (event: AgentEvent): Promise<void> => {
    events.push(event);
    await store.append(sessionId, event);
  };

  let text = "";
  let inputTokens = 0;
  let outputTokens = 0;
  let steps = 0;
  let reason: TurnEndReason = "complete";

  if (opts.prompt !== undefined) {
    await emit({ type: "user_message", text: opts.prompt });
  }

  const messages: Message[] = eventsToMessages(await store.replay(sessionId));

  while (steps < maxSteps) {
    if (signal?.aborted) {
      reason = "cancelled";
      break;
    }
    steps += 1;

    const calls: ToolCall[] = [];
    const partial = new Map<string, { name: string; json: string }>();
    let stepText = "";

    try {
      stream: for await (const delta of provider.streamChat(
        messages,
        schemas,
        signal ? { signal } : undefined,
      )) {
        switch (delta.type) {
          case "text":
            stepText += delta.text;
            await emit({ type: "text", text: delta.text });
            break;
          case "tool_call_start":
            partial.set(delta.id, { name: delta.name, json: "" });
            break;
          case "tool_call_delta": {
            const entry = partial.get(delta.id);
            if (entry) entry.json += delta.argsJsonDelta;
            break;
          }
          case "tool_call_end": {
            const entry = partial.get(delta.id);
            if (entry) {
              calls.push({ id: delta.id, name: entry.name, args: parseArgs(entry.json) });
              partial.delete(delta.id);
            }
            break;
          }
          case "usage":
            inputTokens += delta.inputTokens;
            outputTokens += delta.outputTokens;
            await emit({
              type: "usage",
              inputTokens: delta.inputTokens,
              outputTokens: delta.outputTokens,
            });
            break;
          case "done":
            break stream;
        }
      }
    } catch (error) {
      if (signal?.aborted) {
        reason = "cancelled";
        break;
      }
      await emit(toErrorEvent(error, "provider"));
      reason = "error";
      break;
    }

    text += stepText;

    if (calls.length === 0) {
      reason = "complete";
      break;
    }

    for (const call of calls) {
      const argsHash = hashArgs(call.args);
      const key = `${call.name}:${argsHash}`;
      const count = (repeats.get(key) ?? 0) + 1;
      repeats.set(key, count);

      if (count > maxRepeat) {
        await emit({ type: "loop_detected", name: call.name, argsHash, count });
        reason = "loop";
        break;
      }

      const tool = byName.get(call.name);
      const toolClass: ToolClass = tool?.class ?? "execute";
      await emit({
        type: "tool_call",
        id: call.id,
        name: call.name,
        args: call.args,
        class: toolClass,
      });

      if (!tool) {
        await emit({
          type: "tool_result",
          id: call.id,
          name: call.name,
          ok: false,
          output: `unknown tool: ${call.name}`,
        });
        continue;
      }

      const request: PermissionRequest = { tool: call.name, toolClass, args: call.args };
      const preflight = policy.evaluate(request);
      let decision: ApprovalOutcome = "deny";
      let allowed = false;

      if (preflight.outcome === "allow") {
        decision = "allow";
        allowed = true;
      } else if (preflight.outcome === "deny") {
        decision = "deny";
      } else if (alwaysAllowed.has(call.name)) {
        decision = "always";
        allowed = true;
      } else if (sessionAllowed.has(key)) {
        decision = "session";
        allowed = true;
      } else if (onPermission) {
        decision = await onPermission(request, call.id);
        if (decision === "session") sessionAllowed.add(key);
        if (decision === "always") alwaysAllowed.add(call.name);
        allowed = decision === "allow" || decision === "session" || decision === "always";
      }

      await emit({
        type: "permission_decision",
        id: call.id,
        decision,
        mode: policy.mode,
        argsHash,
      });

      if (!allowed) {
        await emit({
          type: "tool_result",
          id: call.id,
          name: call.name,
          ok: false,
          output: `permission denied (${decision})`,
        });
        continue;
      }

      const ctx: ToolContext = { root, signal };
      try {
        const result = await tool.run(asRecord(call.args), ctx);
        await emit({
          type: "tool_result",
          id: call.id,
          name: call.name,
          ok: result.ok,
          output: result.content,
        });
      } catch (error) {
        await emit(toErrorEvent(error, "tool"));
        await emit({
          type: "tool_result",
          id: call.id,
          name: call.name,
          ok: false,
          output: error instanceof Error ? error.message : String(error),
        });
      }
    }

    if (reason === "loop") break;

    messages.length = 0;
    messages.push(...eventsToMessages(await store.replay(sessionId)));
  }

  if (steps >= maxSteps && reason === "complete") reason = "loop";

  await emit({ type: "turn_end", reason });

  return { reason, text, steps, inputTokens, outputTokens, events };
}
```

- `McpTransport { start(handlers: { onLine; onClose }): void; send(line): void; close(): Promise<void> }` — so tests can drive an in-memory peer without spawning a process.
- `StdioTransport(options: { command; args?; cwd?; env? })` — spawns the server and frames stdout by newline.
- `McpClient({ transport; name?; version? })` with `initialize()`, `listTools(): Promise<McpToolDef[]>`, `tools(namespace?): Tool[]`, `callTool(name, args, ctx?)`, `readonly serverInfo`, `close()`.
- `McpToolDef { name; description?; inputSchema? }`.

MCP tool names are namespaced `mcp__<tool>` by default to avoid colliding with built-ins. MCP tools are always class `execute`, so in `ask` mode they require approval and in `read-only` mode they are denied.

```ts
export interface JsonRpcError {
  code: number;
  message: string;
  data?: unknown;
}

export interface JsonRpcResponse {
  jsonrpc: "2.0";
  id: number;
  result?: unknown;
  error?: JsonRpcError;
}

interface Pending {
  resolve: (value: unknown) => void;
  reject: (error: Error) => void;
}

export class RpcPeer {
  #nextId = 1;
  readonly #pending = new Map<number, Pending>();

  constructor(private readonly write: (line: string) => void) {}

  request(method: string, params?: unknown): Promise<unknown> {
    const id = this.#nextId;
    this.#nextId += 1;
    return new Promise<unknown>((resolve, reject) => {
      this.#pending.set(id, { resolve, reject });
      this.write(JSON.stringify({ jsonrpc: "2.0", id, method, params }));
    });
  }

  notify(method: string, params?: unknown): void {
    this.write(JSON.stringify({ jsonrpc: "2.0", method, params }));
  }

  handle(line: string): void {
    const trimmed = line.trim();
    if (trimmed === "") return;

    let message: JsonRpcResponse;
    try {
      message = JSON.parse(trimmed) as JsonRpcResponse;
    } catch {
      return;
    }

    if (typeof message.id !== "number") return;
    const pending = this.#pending.get(message.id);
    if (!pending) return;
    this.#pending.delete(message.id);

    if (message.error) {
      pending.reject(new Error(`${message.error.code}: ${message.error.message}`));
    } else {
      pending.resolve(message.result);
    }
  }

  rejectAll(error: Error): void {
    for (const pending of this.#pending.values()) pending.reject(error);
    this.#pending.clear();
  }
}
```

```ts
import type { Tool, ToolContext, ToolResult } from "../tools/types.js";
import { RpcPeer } from "./jsonrpc.js";

export interface McpTransport {
  start(handlers: { onLine: (line: string) => void; onClose: (error?: Error) => void }): void;
  send(line: string): void;
  close(): Promise<void>;
}

export interface McpToolDef {
  name: string;
  description?: string;
  inputSchema?: Record<string, unknown>;
}

export interface McpClientOptions {
  transport: McpTransport;
  name?: string;
  version?: string;
}

export interface McpServerInfo {
  name?: string;
  version?: string;
}

const PROTOCOL_VERSION = "2024-11-05";

export class McpClient {
  readonly #peer: RpcPeer;
  readonly #transport: McpTransport;
  readonly #name: string;
  readonly #version: string;
  #tools: McpToolDef[] = [];
  #serverInfo: McpServerInfo = {};
  #closed = false;

  constructor(options: McpClientOptions) {
    this.#transport = options.transport;
    this.#name = options.name ?? "t3os";
    this.#version = options.version ?? "0.1.0";
    this.#peer = new RpcPeer((line) => this.#transport.send(`${line}\n`));
    this.#transport.start({
      onLine: (line) => this.#peer.handle(line),
      onClose: (error) => this.#peer.rejectAll(error ?? new Error("mcp transport closed")),
    });
  }

  get serverInfo(): McpServerInfo {
    return this.#serverInfo;
  }

  async initialize(): Promise<void> {
    const result = (await this.#peer.request("initialize", {
      protocolVersion: PROTOCOL_VERSION,
      capabilities: { tools: {} },
      clientInfo: { name: this.#name, version: this.#version },
    })) as { serverInfo?: McpServerInfo } | undefined;

    this.#serverInfo = result?.serverInfo ?? {};
    this.#peer.notify("notifications/initialized");
  }

  async listTools(): Promise<McpToolDef[]> {
    const result = (await this.#peer.request("tools/list")) as { tools?: McpToolDef[] } | undefined;
    this.#tools = result?.tools ?? [];
    return this.#tools;
  }

  tools(namespace = "mcp"): Tool[] {
    return this.#tools.map((def) => this.#adapt(def, namespace));
  }

  async callTool(name: string, args: Record<string, unknown>): Promise<ToolResult> {
    try {
      const result = (await this.#peer.request("tools/call", { name, arguments: args })) as
        | { content?: { type: string; text?: string }[]; isError?: boolean }
        | undefined;

      const content = result?.content ?? [];
      const text = content
        .map((part) => part.text ?? "")
        .join("\n")
        .trim();

      return {
        ok: result?.isError !== true,
        content: text === "" ? "(no output)" : text,
        data: result,
      };
    } catch (error) {
      return {
        ok: false,
        content: error instanceof Error ? error.message : String(error),
      };
    }
  }

  #adapt(def: McpToolDef, namespace: string): Tool {
    return {
      schema: {
        name: `${namespace}__${def.name}`,
        description: def.description ?? `MCP tool ${def.name}`,
        parameters: def.inputSchema ?? { type: "object" },
      },
      class: "execute",
      run: (args, _ctx: ToolContext) => this.callTool(def.name, args),
    };
  }

  async close(): Promise<void> {
    if (this.#closed) return;
    this.#closed = true;
    await this.#transport.close();
  }
}
```

```ts
import { spawn, type ChildProcessWithoutNullStreams } from "node:child_process";
import type { McpTransport } from "./client.js";

export interface StdioTransportOptions {
  command: string;
  args?: string[];
  cwd?: string;
  env?: Record<string, string>;
}

export class StdioTransport implements McpTransport {
  readonly #options: StdioTransportOptions;
  #child?: ChildProcessWithoutNullStreams;
  #buffer = "";
  #closed = false;

  constructor(options: StdioTransportOptions) {
    this.#options = options;
  }

  start(handlers: { onLine: (line: string) => void; onClose: (error?: Error) => void }): void {
    const child = spawn(this.#options.command, this.#options.args ?? [], {
      cwd: this.#options.cwd,
      env: { ...process.env, ...this.#options.env },
      stdio: ["pipe", "pipe", "pipe"],
    });
    this.#child = child;

    child.stdout.setEncoding("utf8");
    child.stdout.on("data", (chunk: string) => {
      this.#buffer += chunk;
      let index = this.#buffer.indexOf("\n");
      while (index !== -1) {
        handlers.onLine(this.#buffer.slice(0, index));
        this.#buffer = this.#buffer.slice(index + 1);
        index = this.#buffer.indexOf("\n");
      }
    });

    child.on("error", (error) => handlers.onClose(error));
    child.on("close", () => handlers.onClose());
  }

  send(line: string): void {
    this.#child?.stdin.write(line);
  }

  async close(): Promise<void> {
    if (this.#closed) return;
    this.#closed = true;
    const child = this.#child;
    if (child && !child.killed) {
      child.stdin.end();
      child.kill();
    }
  }
}
```

```ts
export interface ParsedArgs {
  command: string;
  positionals: string[];
  flags: Record<string, string | boolean>;
}

export function parseArgs(argv: string[]): ParsedArgs {
  const [command = "help", ...rest] = argv;
  const positionals: string[] = [];
  const flags: Record<string, string | boolean> = {};

  for (let i = 0; i < rest.length; i += 1) {
    const token = rest[i]!;
    if (token.startsWith("--")) {
      const body = token.slice(2);
      const eq = body.indexOf("=");
      if (eq >= 0) {
        flags[body.slice(0, eq)] = body.slice(eq + 1);
      } else {
        const next = rest[i + 1];
        if (next !== undefined && !next.startsWith("-")) {
          flags[body] = next;
          i += 1;
        } else {
          flags[body] = true;
        }
      }
    } else if (token.startsWith("-") && token.length > 1) {
      flags[token.slice(1)] = true;
    } else {
      positionals.push(token);
    }
  }

  return { command, positionals, flags };
}
```

```ts
  if (typeof flags.model === "string") overrides.model = flags.model;
  if (typeof flags.permission === "string") overrides.permissionMode = flags.permission as PermissionMode;

  const loader = new ConfigLoader({ cwd: deps.cwd, homeDir: deps.homeDir, env: deps.env, flags: overrides });

    throw new T3osError("config", "HF_TOKEN is not set; run `t3os auth set <token>`");

async function cmdAuth(deps: CliDeps, args: string[]): Promise<number> {
  const sub = args[0];
  const keyring = deps.keyring ?? systemKeyring;

    const value = args[1];
    if (!value) {
      deps.err("usage: t3os auth set <token>");
      return 1;
    }
    await keyring.set("HF_TOKEN", value);
    deps.out("HF_TOKEN stored");
    return 0;

    const token = await resolveToken(deps);
    deps.out(`HF_TOKEN: ${token ? "configured" : "not configured"}`);
    return 0;

function coerce(key: string, raw: string): unknown {
  if (key === "maxTurns" || key === "loopThreshold") return Number(raw);
  if (key === "toolAllow" || key === "toolDeny") {
    return raw
      .split(",")
      .map((part) => part.trim())
      .filter((part) => part.length > 0);
  }
  return raw;
}

async function writeProjectConfig(cwd: string, key: string, raw: string): Promise<void> {
  const path = join(cwd, ".t3os", "config.json");
  let current: Record<string, unknown> = {};
  try {
    current = JSON.parse(await readFile(path, "utf8")) as Record<string, unknown>;
  } catch {
    current = {};
  }
  current[key] = coerce(key, raw);
  await mkdir(dirname(path), { recursive: true });
  await writeFile(path, `${JSON.stringify(current, null, 2)}\n`, "utf8");
}

async function cmdConfig(deps: CliDeps, args: string[]): Promise<number> {
  const sub = args[0];
  if (sub === "show") {
    const config = await resolveConfig(deps, {});
    for (const key of CONFIG_KEYS) {
      deps.out(`${key}=${JSON.stringify((config as Record<string, unknown>)[key])}`);
    }
    return 0;
  }
  if (sub === "get") {
    const key = args[1];
    if (!key || !CONFIG_KEYS.includes(key as (typeof CONFIG_KEYS)[number])) {
      deps.err(`unknown config key: ${key ?? "(none)"}`);
      return 1;
    }
    const config = await resolveConfig(deps, {});
    deps.out(JSON.stringify((config as Record<string, unknown>)[key]));
    return 0;
  }
  if (sub === "set") {
    const key = args[1];
    const value = args[2];
    if (!key || !value || !CONFIG_KEYS.includes(key as (typeof CONFIG_KEYS)[number])) {
      deps.err(`usage: t3os config set <key> <value>`);
      return 1;
    }
    await writeProjectConfig(deps.cwd, key, value);
    deps.out(`set ${key} in .t3os/config.json`);
    return 0;
  }
  deps.err(`unknown config subcommand: ${sub ?? "(none)"}`);
  return 1;
}

async function cmdRun(deps: CliDeps, positionals: string[], flags: Record<string, string | boolean>): Promise<number> {
  const prompt = positionals.join(" ").trim();
  if (!prompt) {
    deps.err("usage: t3os run <prompt...>");
    return 1;
  }
  const config = await resolveConfig(deps, flags);
  const provider = await (deps.makeProvider ?? defaultProvider)(config, deps);
  const store = new SessionStore(config.sessionDir);
  const session = await store.create(prompt.slice(0, 40));
  const result = await runTurn({
    provider,
    store,
    sessionId: session.id,
    policy: createPolicy(config.permissionMode),
    root: config.projectRoot,
    tools: builtInTools(),
    prompt,
    maxSteps: config.maxTurns,
    maxRepeat: config.loopThreshold,
  });
  for (const event of result.events) {
    if (event.type === "text") deps.out(event.text);
    else if (event.type === "tool_call") deps.out(`[tool] ${event.name}`);
    else if (event.type === "tool_result") deps.out(`[${event.ok ? "ok" : "fail"}] ${event.name}`);
    else if (event.type === "error") deps.err(`[error:${event.scope}] ${event.message}`);
  }
  deps.out(`[turn_end: ${result.reason}]`);
  return result.reason === "error" ? 1 : 0;
}

export async function runCli(argv: string[], deps: CliDeps): Promise<number> {
  const { command, positionals, flags } = parseArgs(argv);
  switch (command) {
    case "help":
    case "--help":
    case "-h":
      deps.out(USAGE);
      return 0;
    case "version":
      deps.out(VERSION);
      return 0;
    case "models":
      return cmdModels(deps);
    case "auth":
      return cmdAuth(deps, positionals);
    case "config":
      return cmdConfig(deps, positionals);
    case "run":
      return cmdRun(deps, positionals, flags);
    default:
      deps.err(`unknown command: ${command}`);
      deps.out(USAGE);
      return 1;
  }
}
```

```ts
import type {
  AgentEvent,
  ErrorScope,
  ToolClass,
  TurnEndReason,
} from "@t3os/core";

export type TranscriptEntry =
  | { kind: "user"; text: string }
  | { kind: "assistant"; text: string }
  | {
      kind: "tool";
      id: string;
      name: string;
      cls: ToolClass;
      args: unknown;
      ok?: boolean;
      output?: string;
    }
  | { kind: "error"; scope: ErrorScope; message: string };

export interface TranscriptState {
  entries: TranscriptEntry[];
  usage: { inputTokens: number; outputTokens: number };
  status: "idle" | "streaming" | "done";
  reason?: TurnEndReason;
}

export function emptyTranscript(): TranscriptState {
  return {
    entries: [],
    usage: { inputTokens: 0, outputTokens: 0 },
    status: "idle",
  };
}

export function reduceTranscript(
  state: TranscriptState,
  event: AgentEvent,
): TranscriptState {
  switch (event.type) {
    case "user_message":
      return {
        ...state,
        status: "streaming",
        entries: [...state.entries, { kind: "user", text: event.text }],
      };
    case "text": {
      const entries = [...state.entries];
      const last = entries[entries.length - 1];
      if (last && last.kind === "assistant") {
        entries[entries.length - 1] = {
          kind: "assistant",
          text: last.text + event.text,
        };
      } else {
        entries.push({ kind: "assistant", text: event.text });
      }
      return { ...state, entries };
    }
    case "tool_call":
      return {
        ...state,
        entries: [
          ...state.entries,
          {
            kind: "tool",
            id: event.id,
            name: event.name,
            cls: event.class,
            args: event.args,
          },
        ],
      };
    case "tool_result": {
      const entries = [...state.entries];
      for (let i = entries.length - 1; i >= 0; i -= 1) {
        const entry = entries[i];
        if (entry && entry.kind === "tool" && entry.id === event.id) {
          entries[i] = { ...entry, ok: event.ok, output: event.output };
          break;
        }
      }
      return { ...state, entries };
    }
    case "loop_detected":
      return {
        ...state,
        entries: [
          ...state.entries,
          {
            kind: "error",
            scope: "tool",
            message: `loop detected: ${event.name} (${event.count}x)`,
          },
        ],
      };
    case "error":
      return {
        ...state,
        entries: [
          ...state.entries,
          { kind: "error", scope: event.scope, message: event.message },
        ],
      };
    case "usage":
      return {
        ...state,
        usage: {
          inputTokens: state.usage.inputTokens + event.inputTokens,
          outputTokens: state.usage.outputTokens + event.outputTokens,
        },
      };
    case "turn_end":
      return { ...state, status: "done", reason: event.reason };
    default:
      return state;
  }
}
```

```tsx
import type { ApprovalOutcome, PermissionRequest } from "@t3os/core";
import type { TranscriptState } from "./transcript.js";

export interface PendingPermission {
  request: PermissionRequest;
  id: string;
}

export interface AppProps {
  state: TranscriptState;
  model: string;
  onSubmit: (text: string) => void;
  busy?: boolean;
  permission?: PendingPermission | null;
  onPermission: (outcome: ApprovalOutcome) => void;

export function App({
  state,
  model,
  onSubmit,
  busy = false,
  permission = null,
  onPermission,
}: AppProps): React.ReactElement {
  const [input, setInput] = useState("");

  useInput((value, key) => {
    if (permission) {
      if (value === "y") onPermission("allow");
      else if (value === "a") onPermission("always");
      else if (value === "d") onPermission("session");
      else if (value === "n") onPermission("deny");
      return;
    }
    if (busy) return;
    if (key.return) {
      if (input.trim().length > 0) onSubmit(input);
      setInput("");
      return;
    }
    if (key.backspace || key.delete) {
      setInput((current) => current.slice(0, -1));
      return;
    }
    if (!key.ctrl && !key.meta && value) {
      setInput((current) => current + value);
    }
  });

  return (
    <Box flexDirection="column">
      <Text color="cyan">t3os · {model}</Text>
      {state.entries.map((entry, index) => {
        if (entry.kind === "user") {
          return (
            <Text key={index} color="green">
              › {entry.text}
            </Text>
          );
        }
        if (entry.kind === "assistant") {
          return <Text key={index}>{entry.text}</Text>;
        }
        if (entry.kind === "tool") {
          const mark = entry.ok === undefined ? "…" : entry.ok ? "ok" : "fail";
          return (
            <Text key={index} color="yellow">
              ⚙ {entry.name} [{mark}]
            </Text>
          );
        }
        return (
          <Text key={index} color="red">
            ! {entry.message}
          </Text>
        );
      })}
      {permission ? (
        <Box flexDirection="column">
          <Text color="magenta">
            permission: {permission.request.tool} ({permission.request.toolClass})
          </Text>
          <Text>[y] allow [a] always [d] this session [n] deny</Text>
        </Box>
      ) : busy ? (
        <Text dimColor>working…</Text>
      ) : (
        <Text color="gray">› {input}</Text>
      )}
    </Box>
  );
}
```

```ts
  onTurnEnd?: (reason: TurnEndReason) => void;
}

export async function startRepl(options: ReplOptions): Promise<void> {
  let state: TranscriptState = emptyTranscript();
  let busy = false;
  let pending: PendingPermission | null = null;
  let resolvePermission: ((outcome: ApprovalOutcome) => void) | null = null;

  const view = (): React.ReactElement =>
    React.createElement(App, {
      state,
      model: options.model,
      busy,
      permission: pending,
      onSubmit: (text: string) => {
        void turn(text);
      },
      onPermission: (outcome: ApprovalOutcome) => {
        const resolve = resolvePermission;
        pending = null;
        resolvePermission = null;
        if (resolve) resolve(outcome);
        else draw();
      },
    });

  const draw = (): void => {
    instance.rerender(view());
  };

  const instance = render(view());

  async function turn(text: string): Promise<void> {
    busy = true;
    state = reduceTranscript(state, { type: "user_message", text });
    draw();
    const result = await runTurn({
      provider: options.provider,
      store: options.store,
      sessionId: options.sessionId,
      policy: options.policy,
      root: options.root,
      tools: builtInTools(),
      onEvent: (event) => {
        state = reduceTranscript(state, event);
        draw();
      },
      onPermission: (request: PermissionRequest, id: string) =>
        new Promise<ApprovalOutcome>((resolve) => {
          pending = { request, id };
          resolvePermission = resolve;
          draw();
        }),
    });
    busy = false;
    draw();
    options.onTurnEnd?.(result.reason);
  }

  await instance.waitUntilExit();
}
```

## Task 15: HTTP and WebSocket server

`@t3os/server` boots the same `packages/core` engine that the TUI runs
in-process, but exposes it over HTTP + WebSocket for the desktop shell (Task 16)
and any other client. The engine is unchanged: the server only adds transport.

- `GET  /health` — liveness probe.
- `GET  /sessions` — list session metadata.
- `POST /sessions` — create a session (`{ "title"?: string }`).

  the `EventBus`. This reuses the `onEvent` callback added to `runTurn` in

```ts
import type { AgentEvent } from "@t3os/core";

export type EventListener = (event: AgentEvent) => void;

export class EventBus {
  #listeners = new Map<string, Set<EventListener>>();

  subscribe(sessionId: string, listener: EventListener): () => void {
    let set = this.#listeners.get(sessionId);
    if (!set) {
      set = new Set();
      this.#listeners.set(sessionId, set);
    }
    set.add(listener);
    return () => {
      set.delete(listener);
      if (set.size === 0) this.#listeners.delete(sessionId);
    };
  }

  publish(sessionId: string, event: AgentEvent): void {
    const set = this.#listeners.get(sessionId);
    if (!set) return;
    for (const listener of set) listener(event);
  }

  subscriberCount(sessionId: string): number {
    return this.#listeners.get(sessionId)?.size ?? 0;
  }
}
```

```ts
import type { IncomingMessage, ServerResponse } from "node:http";
import type { AgentEvent, SessionStore } from "@t3os/core";
import type { EventBus } from "./events.js";

export type TurnRunner = (args: {
  sessionId: string;
  prompt: string;
  onEvent: (event: AgentEvent) => void;
}) => Promise<{ reason: string }>;

export interface AppDeps {
  store: SessionStore;
  bus: EventBus;
  runTurn: TurnRunner;
}

function sendJson(res: ServerResponse, status: number, body: unknown): void {
  res.writeHead(status, { "content-type": "application/json" });
  res.end(JSON.stringify(body));
}

async function readBody(req: IncomingMessage): Promise<unknown> {
  const chunks: Buffer[] = [];
  for await (const chunk of req) chunks.push(chunk as Buffer);
  const raw = Buffer.concat(chunks).toString("utf8");
  if (raw.length === 0) return {};
  try {
    return JSON.parse(raw);
  } catch {
    return undefined;
  }
}

export function createApp(
  deps: AppDeps,
): (req: IncomingMessage, res: ServerResponse) => Promise<void> {
  const { store, bus, runTurn } = deps;

  return async function handle(req, res) {
    const url = new URL(req.url ?? "/", "http://localhost");
    const parts = url.pathname.split("/").filter((part) => part.length > 0);
    const method = req.method ?? "GET";

    if (method === "GET" && parts.length === 1 && parts[0] === "health") {
      sendJson(res, 200, { ok: true });
      return;
    }

    if (parts[0] === "sessions") {
      if (method === "GET" && parts.length === 1) {
        sendJson(res, 200, await store.list());
        return;
      }

      if (method === "POST" && parts.length === 1) {
        const body = await readBody(req);
        if (body === undefined) {
          sendJson(res, 400, { error: "invalid json" });
          return;
        }
        const title =
          typeof (body as { title?: unknown }).title === "string"
            ? (body as { title: string }).title
            : undefined;
        sendJson(res, 201, await store.create(title));
        return;
      }

      if (method === "GET" && parts.length === 2) {
        const id = parts[1]!;
        try {
          sendJson(res, 200, { id, events: await store.replay(id) });
        } catch {
          sendJson(res, 404, { error: "session not found" });
        }
        return;
      }

      if (method === "POST" && parts.length === 3 && parts[2] === "turns") {
        const id = parts[1]!;
        const body = await readBody(req);
        if (body === undefined) {
          sendJson(res, 400, { error: "invalid json" });
          return;
        }
        const prompt =
          typeof (body as { prompt?: unknown }).prompt === "string"
            ? (body as { prompt: string }).prompt
            : "";
        res.writeHead(200, { "content-type": "application/x-ndjson" });
        await runTurn({
          sessionId: id,
          prompt,
          onEvent: (event) => {
            bus.publish(id, event);
            res.write(`${JSON.stringify(event)}\n`);
          },
        });
        res.end();
        return;
      }
    }

    sendJson(res, 404, { error: "not found" });
  };
}
```

```ts
import { createServer, type Server } from "node:http";
import { WebSocketServer } from "ws";
import type { SessionStore } from "@t3os/core";
import { createApp, type TurnRunner } from "./app.js";
import { EventBus } from "./events.js";

export interface ServerOptions {
  store: SessionStore;
  runTurn: TurnRunner;
  port?: number;
  host?: string;
}

export interface RunningServer {
  port: number;
  url: string;
  close(): Promise<void>;
}

export async function startServer(options: ServerOptions): Promise<RunningServer> {
  const host = options.host ?? "127.0.0.1";
  const bus = new EventBus();
  const handle = createApp({ store: options.store, bus, runTurn: options.runTurn });

  const server: Server = createServer((req, res) => {
    void handle(req, res).catch((err: unknown) => {
      res.writeHead(500, { "content-type": "application/json" });
      res.end(JSON.stringify({ error: String(err) }));
    });
  });

  const wss = new WebSocketServer({ noServer: true });

  server.on("upgrade", (req, socket, head) => {
    const url = new URL(req.url ?? "/", "http://localhost");
    const parts = url.pathname.split("/").filter((part) => part.length > 0);
    if (parts.length === 3 && parts[0] === "sessions" && parts[2] === "stream") {
      const sessionId = parts[1]!;
      wss.handleUpgrade(req, socket, head, (ws) => {
        const unsubscribe = bus.subscribe(sessionId, (event) => {
          ws.send(JSON.stringify(event));
        });
        ws.on("close", unsubscribe);
      });
    } else {
      socket.destroy();
    }
  });

  await new Promise<void>((resolve) => server.listen(options.port ?? 0, host, resolve));
  const address = server.address();
  const port = typeof address === "object" && address ? address.port : 0;

  return {
    port,
    url: `http://${host}:${port}`,
    async close() {
      await new Promise<void>((resolve) => wss.close(() => resolve()));
      await new Promise<void>((resolve, reject) =>
        server.close((err) => (err ? reject(err) : resolve())),
      );
    },
  };
}
```

```ts
import type { AgentEvent } from "@t3os/core";

export interface DesktopClientOptions {
  baseUrl: string;
  fetchImpl?: typeof fetch;
  WebSocketImpl?: typeof WebSocket;
}

export interface SessionMeta {
  id: string;
  title: string;
  createdAt: string;
  updatedAt: string;
  eventCount: number;
}

export type ConnectionState = "connecting" | "open" | "closed";

export class DesktopClient {
  readonly #baseUrl: string;
  readonly #fetch: typeof fetch;
  readonly #WebSocket: typeof WebSocket;

  constructor(options: DesktopClientOptions) {
    this.#baseUrl = options.baseUrl.replace(/\/$/, "");
    this.#fetch = options.fetchImpl ?? fetch;
    this.#WebSocket = options.WebSocketImpl ?? WebSocket;
  }

  async #json<T>(path: string, init?: RequestInit): Promise<T> {
    const response = await this.#fetch(`${this.#baseUrl}${path}`, init);
    if (!response.ok) {
      throw new Error(`request failed: ${response.status} ${path}`);
    }
    return (await response.json()) as T;
  }

  async health(): Promise<{ ok: boolean }> {
    return this.#json<{ ok: boolean }>("/health");
  }

  async listSessions(): Promise<SessionMeta[]> {
    return this.#json<SessionMeta[]>("/sessions");
  }

  async createSession(title?: string): Promise<SessionMeta> {
    return this.#json<SessionMeta>("/sessions", {
      method: "POST",
      headers: { "content-type": "application/json" },
      body: JSON.stringify({ title }),
    });
  }

  async getSession(id: string): Promise<{ id: string; events: AgentEvent[] }> {
    return this.#json<{ id: string; events: AgentEvent[] }>(`/sessions/${id}`);
  }

  async *startTurn(id: string, prompt: string): AsyncIterable<AgentEvent> {
    const response = await this.#fetch(`/sessions/${id}/turns`, {
      method: "POST",
      headers: { "content-type": "application/json" },
      body: JSON.stringify({ prompt }),
    });
    if (!response.ok || !response.body) {
      throw new Error(`turn failed: ${response.status}`);
    }
    const reader = response.body.getReader();
    const decoder = new TextDecoder();
    let buffer = "";
    for (;;) {
      const { done, value } = await reader.read();
      if (done) break;
      buffer += decoder.decode(value, { stream: true });
      let newline = buffer.indexOf("\n");
      while (newline !== -1) {
        const line = buffer.slice(0, newline).trim();
        buffer = buffer.slice(newline + 1);
        if (line.length > 0) yield JSON.parse(line) as AgentEvent;
        newline = buffer.indexOf("\n");
      }
    }
    const trailing = buffer.trim();
    if (trailing.length > 0) yield JSON.parse(trailing) as AgentEvent;
  }

  subscribe(
    id: string,
    onEvent: (event: AgentEvent) => void,
    onState?: (state: ConnectionState) => void,
  ): () => void {
    const url = `${this.#baseUrl.replace(/^http/, "ws")}/sessions/${id}/stream`;
    const socket = new this.#WebSocket(url);
    onState?.("connecting");
    socket.addEventListener("open", () => onState?.("open"));
    socket.addEventListener("message", (event: MessageEvent) => {
      onEvent(JSON.parse(String(event.data)) as AgentEvent);
    });
    socket.addEventListener("close", () => onState?.("closed"));
    return () => socket.close();
  }
}
```

```ts
import type { AgentEvent } from "@t3os/core";
import type { DesktopClient } from "./api.js";

export interface MountDeps {
  client: DesktopClient;
  root: HTMLElement;
  createSession?: () => Promise<string>;
}

export function mountDesktop(deps: MountDeps): () => void {
  const { client, root } = deps;
  const createSession = deps.createSession ?? (() => client.createSession().then((s) => s.id));

  root.innerHTML = `
    <div id="t3os">
      <header>t3os</header>
      <div class="transcript" id="transcript"></div>
      <footer>
        <input id="prompt" placeholder="Ask T3OS to do something..." />
      </footer>
    </div>
  `;

  const transcript = root.querySelector<HTMLDivElement>("#transcript");
  const input = root.querySelector<HTMLInputElement>("#prompt");
  let sessionId: string | null = null;

  const append = (kind: string, text: string): void => {
    if (!transcript) return;
    const entry = document.createElement("div");
    entry.className = "entry";
    entry.dataset.kind = kind;
    entry.textContent = text;
    transcript.appendChild(entry);
  };

  const handleEvent = (event: AgentEvent): void => {
    if (event.type === "user_message") append("user", `> ${event.text}`);
    else if (event.type === "text") append("assistant", event.text);
    else if (event.type === "tool_call") append("tool", `${event.name} [${event.class}]`);
    else if (event.type === "tool_result") append("tool", `${event.name} [${event.ok ? "ok" : "fail"}]`);
    else if (event.type === "error") append("error", event.message);
  };

  const submit = async (): Promise<void> => {
    if (!input) return;
    const prompt = input.value.trim();
    if (prompt.length === 0) return;
    input.value = "";
    if (!sessionId) sessionId = await createSession();
    for await (const event of client.startTurn(sessionId, prompt)) handleEvent(event);
  };

  const onKeyDown = (event: KeyboardEvent): void => {
    if (event.key === "Enter") void submit();
  };
  input?.addEventListener("keydown", onKeyDown);

  return () => {
    input?.removeEventListener("keydown", onKeyDown);
    root.innerHTML = "";
  };
}
```

```ts
  const handler = createApp({ store, bus, runTurn: runTurnImpl });
  const server: Server = createServer((req, res) => void handler(req, res));
  await new Promise<void>((resolve) => server.listen(0, "127.0.0.1", resolve));
  const address = server.address();
  const port = typeof address === "object" && address ? address.port : 0;
  return {
    url: `http://127.0.0.1:${port}`,
    close: () => new Promise<void>((resolve) => server.close(() => resolve())),
  };
}

describe("end-to-end turn over HTTP", () => {
  let h: Harness;

  beforeEach(async () => {
    h = await harness();
  });

  afterEach(async () => {
    await h.close();
  });

  it("streams the golden event sequence as NDJSON", async () => {
    const created = await fetch(`${h.url}/sessions`, {
      method: "POST",
      headers: { "content-type": "application/json" },
      body: JSON.stringify({ title: "e2e" }),
    });
    const session = (await created.json()) as { id: string };

    const response = await fetch(`${h.url}/sessions/${session.id}/turns`, {
      method: "POST",
      headers: { "content-type": "application/json" },
      body: JSON.stringify({ prompt: "echo hi" }),
    });
    const text = await response.text();
    const events = text
      .split("\n")
      .filter((line) => line.trim().length > 0)
      .map((line) => JSON.parse(line) as AgentEvent);

    const golden = (await readFile(GOLDEN, "utf8"))
      .split("\n")
      .filter((line) => line.trim().length > 0)
      .map((line) => JSON.parse(line) as unknown);

    expect(normalizeEvents(events)).toEqual(golden);
  });
});
```

      package names; `.js` ESM import specifiers throughout.
- [ ] **TDD shape**: each task writes a failing test, runs it, implements, runs it
      green, runs the full suite, then commits with a unique message.
- [ ] **Security**: secrets only via `SecretResolver`; `HF_TOKEN` never logged;
      hard deny-list evaluated before the permission matrix; path resolution
      confined to the workspace root.

## Execution Handoff

The plan is complete and ready to execute. Two supported paths:

- **Subagent-driven** (`subagent-driven-development`): dispatch one fresh
  subagent per task, in order, verifying each task's tests before moving on.
- **Inline** (`executing-plans`): work the tasks top to bottom in this session,

Either way: execute tasks **in order** (later tasks import earlier ones), never
skip the failing-test step, and stop at the first red suite rather than pushing
